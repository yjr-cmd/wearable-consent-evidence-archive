# wearable-consent-evidence-archive

Supplementary materials and archived sources for a documentary analysis of informed-consent safeguards in Chinese wearable-device privacy policies.

## Repository contents

The repository contains the materials supporting the documentary analysis of 18 wearable-device cases:

1. `Evidence Matrix_English.xlsx` — auditable English evidence matrix.
2. `Document Selection_Flow_Diagram.docx` — document-selection flow diagram.
3. `Cohens Kappa Assessment_English.docx` — English inter-coder reliability assessment.
4. `07_Privacy_Policy_Archive_AG01_AG18.zip` — archived source-document set for AG01–AG18, including searchable Markdown texts, controlling original policy snapshots, available supporting third-party or SDK materials, and archive manifests.
5. `Coding Manual.docx` — coding definitions and decision rules.
6. `Device and Document Applicability Inventory_English.docx` — case-level device, document, source, and conditional-indicator applicability inventory.
7. `Supplementary Screening_Table.docx` — traceable candidate-case screening table.

## Archive notes

The archive manifest identifies the materials available for each case. AG05 and AG07 do not have separately archived third-party lists; the assessment for those cases is based on the primary policy text. Supporting attachments supplement, but do not replace, the primary policy documents used for coding.
